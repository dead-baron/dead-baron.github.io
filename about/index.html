ABOUT DEAD BARON

Dead Baron is a one-person game project focused on quick, good-looking arcade games that run in any modern browser.

The idea is simple: a game should load in a second, feel smooth on an everyday phone, and let you play a friend without making accounts or installing anything. Neon Asteroids is the first release — a head-to-head reimagining of a classic arcade shooter, with a glowing vector look inspired by the golden age of arcade cabinets.

HOW THE GAMES ARE MADE

Each game is a single web page written in plain JavaScript and HTML5 Canvas. Multiplayer connects players' devices directly to each other (peer-to-peer), which keeps lag low and means there's no game server holding your data. Development is done with the help of Claude, an AI assistant made by Anthropic, used as a coding partner for design, programming and testing.

WHAT'S NEXT

Neon Asteroids keeps getting updates based on player feedback — new ship colors, smoother performance and better matchmaking so far. More games are planned. If you have an idea, a bug report or just want to say hi, get in touch.
